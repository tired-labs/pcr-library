## Overview

High-level overview of the detection and the attack technique/procedure it
covers.

## Coverage Specifics

Detailed description of the coverage of the procedure. For a detection,
this is how the detection is built: what it looks for, how
that identifies the procedure, and what allowlisting the query includes.

## Existing Controls

Description of existing security controls, configurations, or other detections
that cover the same procedure.

## Known Gaps

Identify any known gaps in the detection's ability to identify the target
procedure.

## Long-Term Considerations

Address any possible long term issues or opportunities for the detection.
